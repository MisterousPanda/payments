# The Clearing

A lesson in how a US LLC gets paid: cards, Apple Pay, Google Pay, Venmo, bank debits, and USDC on Solana.

No payment rail is connected. The pages do not charge a card, open Plaid, or talk to a Solana mainnet wallet. Figures are public US prices reviewed on October 10, 2026, and they change.

```bash
npm install
npm run dev
```

Open the site and start on the picture. Setup, cards, bank, and USDC are the chapters. Studio is the practice. Words is the glossary.
